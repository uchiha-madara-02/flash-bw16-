# 🌀 Madara Web Flasher

A browser‑based serial flashing tool for **AmebaD (RTL8720DN / BW16)** and **ESP32/ESP8266** microcontrollers.  
Built with Web Serial API, Tailwind CSS, and esptool‑js – no desktop software required.

![Madara UI](https://img.shields.io/badge/status-futuristic-red?style=for-the-badge)  
*Cyberpunk interface inspired by Uchiha Madara.*

---

## 🚀 Quick Start

1. **Open `index.html`** in a **Chromium‑based browser** (Chrome / Edge ≥ 89).  
   *Firefox / Safari do not support Web Serial yet.*
2. Allow the browser to access your serial port when prompted.
3. Select your target architecture on the welcome screen:
   - **AMEBA_D** → RTL8720DN / BW16
   - **ESP_CORE** → ESP32 / ESP8266
4. Choose firmware files and click **FLASH_DEVICE**.

## 🧰 AMEBA_D (BW16) Usage

The Ameba tool uses the Realtek **Image Tool** protocol over serial.

### Simple Mode (recommended)
- Bootloaders **KM0** and **KM4** are already embedded in the tool.
- You only need to select your **application firmware** (`km0_km4_image2.bin`).
- The tool writes:
  - `0x8000000` – KM0 bootloader
  - `0x8004000` – KM4 bootloader
  - `0x8006000` – Application

### Advanced Mode
- Provide a **flashloader** binary (loaded at `0x082000` RAM).
- Add any number of firmware vectors with custom **address + file**.
- Flashloader is injected into RAM first, then used to write the other images.

### Entering Bootloader Mode
The tool tries to trigger the ROM download mode automatically. If that fails:
1. Press and **hold** the **DOWNLOAD** (or **BOOT**) button.
2. Press and release the **RESET** button.
3. Release the **DOWNLOAD** button.

## 🌐 ESP_CORE Usage

Always uses **Advanced Mode** with [esptool‑js](https://github.com/espressif/esptool-js).

1. Add one or more firmware entries: **address** + **file**.
2. Typical mapping:
   - Bootloader at `0x1000`
   - Partition table at `0x8000`
   - Application at `0x10000`
3. Click **FLASH_DEVICE**. The tool will sync, detect the chip, erase necessary sectors (only those being written) and flash.

## 🔌 Serial Monitor

At the bottom of the page:

1. Click **Connect Monitor** to open a terminal session on the current COM port.
2. Choose the **baud rate** (default 115200).
3. Type commands and hit **Send** (or Enter).
4. **RST** button toggles DTR/RTS to reset the board.
5. **Autoscroll** keeps the log at the bottom.

> **Note:** The monitor and the flasher cannot use the same port simultaneously.  
> The monitor automatically disconnects when you start flashing.

## ⚙️ Advanced

### Baud Rate
Select a baud rate before flashing. The tool will negotiate with the bootloader to switch to a faster rate (when possible).

### Progress & Logs
- Detailed log appears in the **Console Output** area.
- Progress bar indicates current operation (erase, write, etc.).
- Errors are shown in **red**, system messages in **cyan**.

### Hidden Overlay
Press **Ctrl + Alt + C** (Windows/Linux) or **Cmd + Alt + C** (macOS) to toggle a secret “Uchiha Madara” animation. Click to dismiss.

## 🔒 Security & Obfuscation

To protect intellectual property, the entire UI and logic can be obfuscated:

1. Copy the content of the `<script type="module">` tag (from `import ...` to the end).
2. Paste it into [obfuscator.io](https://obfuscator.io).
3. Click **Obfuscate**.
4. Replace the original script block with the obfuscated code.

All HTML markup is dynamically generated by JavaScript, so it remains functional.

## 🐛 Troubleshooting

- **“Failed to execute ‘requestPort’”** → Use a supported browser or enable `#enable-experimental-web-platform-features` in flags.
- **Sync timeout / no response** → Manually enter bootloader mode (see above). Check USB driver (CP210x, CH340, etc.).
- **Write failed at packet X** → Reduce baud rate. Ensure the board has enough power.
- **ESP flashing fails with “Invalid head of packet”** → Try lowering baud rate and re‑select the serial port.
